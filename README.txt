# Aymen Tayari — Technical Portfolio

A responsive, single-page HTML/CSS portfolio in English.

## Preview
Open `index.html` in a browser.

## Before publishing
1. Replace the LinkedIn and GitHub URLs in `index.html` with your personal profile links.
2. Confirm the CV file is present as `CV_Aymen_Tayari.pdf`.
3. You can publish this folder with GitHub Pages, Netlify, or another static hosting provider.

No build tools or JavaScript framework are required.
